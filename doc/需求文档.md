# 需求文档

本文档由开发日志（git 提交历史）还原整理，记录本项目立项至今沉淀的全部需求条目，与三份既有文档交叉核对后成文。每条需求标注落地该需求的提交哈希（可 `git show <hash>` 追溯原始背景）；除"非目标"外，所有条目均已实现并带回归测试。

新增需求时在对应需求域下顺延编号，不要复用或改写已有编号。

## 9. 非目标（明确不做）

以下为设计阶段明确排除的边界（acf8323，设计文档 §1.3），不属于需求缺口：

- 不接真实后端接口：原型阶段数据为静态 mock，通过 JSON 声明。
- 不做运行时全动态能力（如运行时修改 schema 并热更新）。
- 不做可视化拖拽编辑器：JSON 手写即可。
